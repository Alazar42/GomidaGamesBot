# 📢 /notify Command Guide

## Quick Start

**Only available to:** @gomidasolutions username

### How to Send a Notification

1. **Start the command:**
   ```
   /notify
   ```

2. **Send your message:**
   - Type a text message, OR
   - Send a photo with a caption
   - Send `/cancel` to abort

3. **Review the preview:**
   - Your message appears with a preview
   - Buttons: **Yes ✅** or **No ❌**

4. **Confirm:**
   - Click **Yes ✅** to broadcast to all users
   - Click **No ❌** to cancel

---

## Examples

### Text-only notification:
```
/notify
→ Send: "🎮 New game update live!"
→ Preview shown
→ Click Yes ✅ to send to all subscribers
```

### Photo + caption:
```
/notify
→ Send photo with caption: "Check out this awesome prize!"
→ Preview shown
→ Click Yes ✅ to send photo to all subscribers
```

---

## Features

✅ **Recipients:** All users who started the bot + Google Sheet list (if configured)  
✅ **Media:** Text or photos with captions  
✅ **Confirmation:** Always review before broadcasting  
✅ **Status:** Shows count of users who received the message

---

## Troubleshooting

- **"You are not authorized"** → Only @gomidasolutions can use this command
- **"0 subscribers sent"** → No users in the system yet or database unavailable
- No button appears? → /cancel and try again
